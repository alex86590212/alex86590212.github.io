# alex86590212.github.io

Personal site of Alexandru Baris Eroglu, served by GitHub Pages from the root of `main`. Static, no build step.

- `index.html` – page markup
- `assets/style.css`, `assets/main.js` – styles and behaviour
- `assets/hero-bg.webp`, `assets/robot.mp4`, `assets/robot-poster.webp` – hero background and robot video
- `assets/band-*.webp` – section transition bands

Preview locally with `python3 -m http.server` and open http://localhost:8000.
